# 公平待客暨金融友善週報

網站：https://finsustcf.github.io/tcf/

## 閱讀與下載

一般同仁不需登入。「週報閱讀」提供上週週報、本週資訊與自訂期間；「歷史週報」讀取已封存版本；「知識庫」可搜尋名詞、別名與相關資訊。

- 重點名稱隨期間變成「上週重點」「本週重點」「自訂期間重點」；封存版為「該週重點」。每張重點卡都可查看相關資訊。
- 搜尋、主題、國內外來源可篩選文章。未勾選時下載所有篩選結果；勾選後只下載所選資訊。更換條件會清除勾選。
- Excel、Word、PowerPoint 按鈕樣式一致，使用已儲存的資料匯出，不另外呼叫 Gemini。Excel 長摘要分續列；Word 長文自然分頁；PowerPoint 長文分成續頁。
- 三種 Office 都保留原文與附件的可點擊連結。附件只提供名稱與連結，不下載或送入 AI；沒有足夠網頁文字時標示「詳細內容請參閱附件。」。
- 單次期間最多讀取 4,000 則；PowerPoint 每次最多匯出 200 則。超出時會顯示原因，請縮短期間。

## 日期與排程

日期使用 `YYYY/MM/DD`；更新時間使用 `YYYY/MM/DD HH:mm`，24 小時制。

| 臺灣時間 | 工作 |
| --- | --- |
| 每日 08:00、12:00、16:00 | 蒐集來源並接續未完成項目 |
| 每週一 00:00 | 啟動最後一次蒐集，完成後封存上週週報 |

週報依臺灣日期分類。有時區的發布時間先換算，例如美國東岸星期日 20:00（UTC−4）是臺灣星期一 08:00，歸入新的一週。來源只有日期時保留其日期，不推測發布時刻；沒有發布日期時標示收錄日期。週一 00:00 是啟動時間，實際完成時間依來源和服務狀態而異。

## 管理

右上角「管理設定」以 Google 登入。管理員沿用 Firebase `admins/<UID>` 文件的 `enabled: true`。一般閱讀、歷史週報與下載不需登入。

- 更新狀態：最近一次更新、新增數、待處理數與失敗原因；可暫停／開啟自動更新、立即更新、重新彙整上週週報。
- 資訊來源：啟用／停用、新增來源、補齊預設來源；來源網址仍須符合後端允許網域。
- 新增資訊：提交公開網址，可補貼該網址的公開文字。
- 編輯／移除：移除前須確認；誤按可從「已移除資訊」還原。還原維持原期間，不當成今天的新資訊。封存週報保持原版本；需要更新時重新彙整。

介面不提供用量設定、人工審核或獨立失敗重試按鈕。後端分析上限仍保留，既有設定不會被這次更新提高；未完成項目在後續更新時依退避時間接續，服務持續失敗時仍會留待處理並顯示原因。

## 知識庫

初始收錄少量附有官方來源的詞條；後續在文章分析同一次呼叫中擷取文章明確解釋的名詞。別名會用來合併詞條，不在閱讀或下載時重新分析。可查看簡明解釋、與銀行業務的關係、參考來源與相關文章。相關文章最多保留最近 120 個 ID，且只顯示仍公開的資訊。

## 技術與資料

GitHub Pages 靜態前端搭配 Firebase Authentication、Cloud Firestore、Cloud Functions、Cloud Scheduler 與 Secret Manager。只處理公開資料，不含公司文件。`firebase-config.js` 的 Firebase 網頁設定是公開連線資訊；Gemini 私密金鑰僅存後端 Secret Manager，勿貼入 GitHub。

本次需搭配「雙平台後端」更新，不能只替換前端。舊文章不會因更新自動重新分析，既有封存版也不會自動新增附件、詞條或重算日期。新的處理流程從更新後開始生效。
