# 公平待客暨金融友善週報

網址：https://finsustcf.github.io/tcf/

## 閱讀與下載

週報閱讀包含上週週報、本週資訊、自訂期間；另有歷史週報及知識庫。一般閱讀與下載不需登入。點標題或「閱讀內容→」開啟文章。列表左右保留內距；自訂期間套用後日期欄位不隱藏。

資訊右上可下載Excel、Word、PowerPoint；勾選後只匯出所選文章，否則下載目前篩選結果。完整上週／歷史週報附保存的完整重點，其他篩選範圍不混入整週重點。各篇使用「重點摘要」「值得關注」，原文與附件網址以文字附在各篇，不另重複彙整來源附錄。Word與PowerPoint長文續頁，不用刪節號裁切。

## 管理

登入沿用admins/UID的enabled設定。資訊的移除按鈕在本週／自訂期間文章視窗底部，入口維持現狀；已移除資訊可還原或確認後永久刪除，封存週報保留原內容。

「待處理資訊」列出目前未完成文章與啟用來源的讀取錯誤，文章可按略過並確認，停止後續處理。同網址不會重新排入。來源問題請到資訊來源區停用。啟用與停用採不同底色。明細不按24小時自動清除，也不重複堆疊歷次錯誤。

國際清算銀行／巴塞爾委員會與Finextra已從來源設定及預設清單移除，既有公開文章保留。「補齊預設來源」及「縮短既有週報重點」操作區已移除，新週報仍使用精簡重點。

右下角固定文字「問題回報」，無外框或底色。類型、說明、信箱全部必填，不需登入；管理員在管理設定查看，登出清除私人快取。回報有基本限流與防重複寫入，並不自動寄信。
