# 公平待客暨金融友善週報

[開啟網站](https://finsustcf.github.io/tcf/)

## 閱讀與下載

進站預設顯示「本週資訊」，依台灣時間週一換週。「上週週報」可閱讀既有封存版本，「歷史週報」選一週即可查看目前已收錄的公開文章。自訂期間最早可從 2025-12-29 選起。

本週、上週與歷史週報的「收錄新聞一覽」按日期由新到舊排列，日期靠右顯示。點標題可跳到文章卡片。各篇詳情有摘要、原文及可用附件連結。

一般閱讀與下載無需登入。可匯出 Excel、Word 或 PowerPoint，勾選文章時下載所選文章，否則下載目前篩選結果。知識庫的「其他」可查閱沒有現有主題的詞條。

## 管理

管理員可在回補頁點一週七天的日期格查看當天紀錄。日期格只標示「已搜尋」或「未搜尋」，收錄篇數與來源問題在當天紀錄顯示。曾搜尋過的日期重新執行時仍顯示「已搜尋」。

待處理文章可略過，來源失敗警告可單筆或批次清除。移除的文章可從管理設定還原，或經確認後永久刪除。問題回報有基本限流與防重複寫入，管理員可在設定中查看。
