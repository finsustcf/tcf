# 公平待客暨金融友善週報

網站：https://finsustcf.github.io/tcf/

## 閱讀架構

- **週報閱讀**：上週週報、本週資訊、自訂期間。選中選項保持主色底與白字；點選自訂期間立即切換選中狀態；按「套用期間」後日期欄位繼續顯示，套用按鈕為淺底、滑鼠移過時變色。
- **歷史週報**：先選週次，進入後仍留在歷史週報頁籤，可返回列表尋找其他週；不顯示上週／本週／自訂三個期間按鈕。
- **知識庫**：依序顯示名詞、縮寫、中譯、解釋四欄；名詞優先英文全名，沒有英文則用中文。搜尋涵蓋四欄與別名，可依主題篩選；詞條不再展開額外內容。

上週週報優先使用已封存版本；尚未封存時可閱讀已收錄文章。歷史週報讀取該週封存內容。本週與自訂期間讀取目前公開文章。

## 重點與下載

整體重點只放在上週週報及歷史週報，最多三點。新重點在後端彙整週報時產生，儲存後供網站與 Office 共用；閱讀、搜尋、下載不另外呼叫 AI。本週與自訂期間不顯示整體重點。既有完整且可用的封存重點保留；舊版截斷或不完整的內容不再當成完整重點顯示。

下載區位於資訊區塊標題右側，Excel、Word、PowerPoint 使用相同樣式。下方提供搜尋、主題、全部來源、全部類型及文章選取。點文章標題或「閱讀內容 →」開啟同一閱讀視窗。

| 操作 | 匯出範圍 |
| --- | --- |
| 未選取文章 | 目前篩選列表全部文章，包含尚未展開的資料 |
| 選取單篇或多篇 | 只下載已選取的文章 |
| 完整上週或歷史週報 | 附上該週已保存的重點 |
| 只選部分文章、使用篩選或本週／自訂期間 | 不附整週重點 |

變更期間或篩選會清除選取。「選取全部文章」與「取消選取」會同步更新已選數及下載範圍。

Excel、Word、PowerPoint 各篇文章包含標題、發布或收錄日期、地區、來源、摘要、值得關注、完整原文與附件網址。網址以一般文字顯示，不另建立超連結；Office 軟體可能自行辨識網址。取消最後重複的來源附錄／工作表。長文保留完整內容，Excel 分續列、PowerPoint 分頁。

一般同仁不需登入。每次最多讀取 4,000 則；PowerPoint 每次最多匯出 200 則，超出會提示縮短期間。

## 知識庫如何累積

前端附有具官方參考來源的基礎詞條，無須等待初始化即可閱讀；後端詞條讀取失敗時保留既有內容並顯示原因。後端初始化或後續更新會補齊同一批詞條，新文章分析時在同一次請求中擷取文章明確解釋的名詞，合併別名。一般閱讀不使用 AI。

不會自動大量分析歷年文章。舊詞條相容既有名稱與別名，初始化時只補缺少的英文名、縮寫與中譯，不覆寫既有解釋。前台不顯示參考來源、相關文章或銀行值得關注等額外區塊。

## 管理與排程

右上角使用 Google 登入；沿用 `admins/<UID>` 的 `enabled: true` 管理員設定。可啟用／暫停自動更新、立即更新、重新彙整上週週報、新增來源與資訊、編輯、移除及還原。來源僅限後端核准的公開 HTTPS 網域。移除需確認，可在已移除資訊還原；封存版不隨文章移除自動改寫。

每日臺灣時間 08:00、12:00、16:00 蒐集；週一 00:00 啟動最後蒐集後彙整上週。週報分類仍依已確認的時間規則：有時區的發布時間換算臺灣日期；只有日期時保留來源日期；無發布日期則使用收錄日期。網站與 Office 不再顯示時間規則說明句。

附件只提供名稱與公開網址，不下載或送入 AI。沒有足夠網頁文字時標示「詳細內容請參閱附件。」。

## 後端與費用控制

沿用 Firebase 專案 `finsustcf-week`、既有 Google 登入與各自的 Gemini Secret。兩平台資料集合及平台分析計數分開；不同金鑰若屬同一 Gemini 專案，仍可能共用服務配額。

本版保留較低 CPU 設定 `cpu: gcf_gen1`、`concurrency: 1`、`maxInstances: 1`、記憶體 1 GiB。既有每日及每次分析上限不提高。一份週報的新重點最多使用一次分析請求，計入該平台當日上限；同內容重新封存會沿用已完成的重點，避免重複分析。沒有可分析文章或未完成重點時不虛構摘要。

週報重點依優先程度、官方來源與監理期限等條件，從該週資料挑選最多 40 篇有效文章摘要整理，不代表全面市場調查。來源網站、雲端配額或模型服務失敗時，會保留文章與失敗原因；管理員可於服務恢復後重新彙整上週週報。

## 更新

前端所有檔案（含 index.html、data.js 與 vendor）放在對應 GitHub 儲存庫根目錄。這次需要配套後端更新，依更新包 `backend/README.md` 執行分批腳本。勿將 Gemini 私密金鑰貼入前端或 GitHub。Firebase 網頁設定只用於網站連線，不是 Gemini 金鑰。

## 媒體來源修正

舊版預設只有三個官方／相關機構來源。本版補入中央通訊社財經與 Finextra 金融媒體，包含國內外來源，經關鍵字及銀行關聯性篩選後才送分析。下一次初始化或蒐集會補齊缺少的來源；不提高既有分析上限。來源網站阻擋或沒有相關報導時，不保證每次都有媒體文章。
